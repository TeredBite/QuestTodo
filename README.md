# Quest To-Do

Приложение, которое превращает твои повседневные дела в эпичные квесты с помощью ИИ. Запиши задачу — получи сюжет, награды и опыт в навыки.

> **.NET MAUI** | **C#** | **OpenRouter API**

---

## Возможности

- **Генерация квестов** — ИИ создаёт эпичное описание задания, ставки и награду на основе твоего дела и заметок
- **Автоматическое определение** — ИИ сам выбирает сложность (1–3), подходящие навыки и количество опыта (10–100 XP)
- **Прокачка навыков** — выполняй задачи, получай опыт и повышай уровень скиллов
- **Кампании** — настрой мир (сеттинг), цель героя и настроение квестов (8 вариантов: серьёзное, юмористическое, тёмное, эпическое и др.)
- **Полностью на русском** — весь интерфейс и тексты квестов на русском языке

## Установка

### Требования

- [.NET 9 SDK](https://dotnet.microsoft.com/download)
- [Visual Studio 2022](https://visualstudio.microsoft.com/) с workload `.NET MAUI`
- OpenRouter API ключ ([получить](https://openrouter.ai/keys))

### Сборка

```bash
git clone <репозиторий>
cd QuestTodo
dotnet restore
dotnet build
```

### Запуск

```bash
# Windows
dotnet run -f net9.0-windows10.0.19041.0

# Android (эмулятор или устройство)
dotnet run -f net9.0-android

# iOS (требуется macOS)
dotnet run -f net9.0-ios
```

## Как это работает

1. **Создаёшь дело** — вводишь название и опциональные заметки
2. **Генерируешь квест** — ИИ придумывает:
   - Заголовок квеста
   - Описание в терминах мира
   - Что будет, если отложить (stakes)
   - Награду в лоре
   - Сложность (⭐ 1–3)
   - Навыки, которые прокачаются
   - Опыт (+10–100 XP)
3. **Сохраняешь** — квест фиксируется, кнопка генерации пропадает
4. **Выполняешь** — нажимаешь «Выполнено», опыт распределяется по навыкам

## Настроение квестов

| Ключ | Название | Описание |
|------|----------|----------|
| `serious` | Серьёзное | Эпичные и драматичные квесты |
| `humorous` | Юмористическое | Лёгкие и забавные приключения |
| `dark` | Тёмное | Мрачная фэнтези, опасности и жертвы |
| `epic` | Эпическое | Судьбоносные решения, величие и героизм |
| `casual` | Повседневное | Уютные, спокойные истории |
| `noir` | Нуар | Интриги, предательства, моральные дилеммы |
| `horror` | Хоррор | Ужасы, выживание, паранормальное |
| `romantic` | Романтическое | Чувства, отношения, личный рост |
